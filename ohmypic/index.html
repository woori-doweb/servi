ohMypic

폴더의 이미지를 썸네일로 훑고, 한 장을 크게 보고, 여러 장을 한 번에 편집하는 Windows 이미지 뷰어입니다.

내려받기 릴리스 노트

Windows 10 1809+ / 11 (x64) · zip 배포본 · GitHub 릴리스 · SHA-256

할 수 있는 일

창 하나에 목록보기와 크게보기 두 가지 모드가 있습니다.

목록보기

폴더 트리, 썸네일·아이콘·목록·자세히·필름스트립 보기, 이름·종류·크기·날짜 정렬, 미리보기와 카메라 정보 창.

크게보기

포인터 기준 휠 확대, 실제 크기·창에 맞추기, 내비게이터, 전체 화면. 화살표와 Space로 다음 이미지로 넘깁니다.

연속보기

F5로 시작합니다. 이미지당 시간과 페이드 효과를 환경설정에서 정합니다.

편집

회전하기, 크기변경, 포맷변환. JPEG는 크기가 맞으면 화질 손실 없이 회전합니다.

일괄편집

여러 이미지의 크기변경·회전·이름 바꾸기·포맷변환을 한 번에 처리합니다.

탐색기 메뉴

이미지를 오른쪽 클릭해 열기·연속보기·회전·크기변경·포맷변환·일괄편집. 현재 사용자 범위에만 등록합니다.

설치와 업데이트

설치 프로그램 없이 압축을 풀어 실행합니다.

  • Windows 10 1809 이상 또는 Windows 11 (x64)
  • .NET Desktop Runtime 9 (x64) — 없으면 처음 실행할 때 Windows가 설치를 안내합니다.
  • 받은 zip을 원하는 폴더에 풀고 ohMypic.exe를 실행합니다. 인자 없이 열면 사진 폴더를 엽니다.
  • BMP·GIF·JPEG·PNG·TIFF·ICO·JPEG XR. WebP·HEIC·AVIF는 해당 Windows 확장 코덱이 있을 때 열립니다.
  • 새 버전은 하루 한 번 확인하고 창을 닫을 때 설치합니다. 환경설정에서 끌 수 있습니다.

미리보기 단계의 배포본입니다. 아직 코드 서명이 없어 처음 실행할 때 Windows가 경고할 수 있습니다.

git clone https://github.com/woori-doweb/ohmyzip.git

ohMypic 소스는 저장소의 ohmypic/ 폴더에 있습니다.

자주 묻는 질문

ohMypic은 무료인가요?

네. 무료로 내려받아 쓸 수 있고, 소스 코드는 GitHub woori-doweb/ohmyzip 저장소의 ohmypic 폴더에 공개되어 있습니다.

어떤 이미지 형식을 열 수 있나요?

BMP, GIF, JPEG, PNG, TIFF, ICO, JPEG XR을 엽니다. WebP, HEIC, HEIF, AVIF는 해당 Windows 확장 코덱이 설치되어 있을 때 열립니다.

설치가 필요한가요?

설치 프로그램은 없습니다. 받은 zip을 원하는 폴더에 풀고 ohMypic.exe를 실행합니다. .NET Desktop Runtime 9(x64)가 필요하며, 없으면 처음 실행할 때 Windows가 설치를 안내합니다.

JPEG를 회전하면 화질이 떨어지나요?

이미지 크기가 JPEG 블록 단위에 맞으면 화질 손실 없이 회전합니다.

여러 이미지를 한 번에 바꿀 수 있나요?

일괄편집(Ctrl+M)으로 크기변경, 회전, 이름 바꾸기, 포맷변환을 여러 이미지에 한 번에 적용합니다.

미리보기 단계란 무엇인가요?

ohMypic은 아직 정식 버전 전이며 GitHub에 사전 릴리스(prerelease)로 배포됩니다. 기능과 화면이 바뀔 수 있습니다.
