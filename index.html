내려받는 방법

Windows 앱은 설치 프로그램 없이 압축 파일 하나로 배포하고, 모든 릴리스는 GitHub에 공개되어 있습니다. 웹 서비스는 내려받을 것 없이 바로 쓰기로 엽니다.

배포본 받기

제품 카드의 내려받기를 누르면 GitHub 릴리스의 최신 win-x64.zip을 받습니다. 같은 릴리스에 SHA-256 파일이 함께 있습니다.

압축 풀고 실행

원하는 폴더에 풀고 .exe를 실행합니다. .NET Desktop Runtime 9(x64)가 필요합니다. 이후 업데이트는 앱이 스스로 확인합니다.

git으로 소스 받기

ohmyZip과 ohMypic의 소스 전체를 받아 직접 빌드할 수 있습니다.

git clone https://github.com/woori-doweb/ohmyzip.git
