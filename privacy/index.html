개인정보처리방침

servi.im은 회원가입·문의 양식이 없고 이름·이메일 같은 정보를 받지 않습니다. 방문 통계는 동의한 경우에만 수집합니다.

servi(이하 "운영자")는 servi.im(이하 "사이트")을 운영하며 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 관련 고충을 처리하기 위해 이 방침을 둡니다.

1. 쿠키 동의 상태와 변경

현재 이 브라우저의 선택: JavaScript가 꺼져 있어 방문 통계를 불러오지 않습니다

모든 페이지 아래쪽의 "쿠키 설정"에서도 언제든 동의하거나 철회할 수 있습니다. 철회하면 그 즉시 전송을 멈추고 이 사이트의 Google 애널리틱스 쿠키(_ga, _ga_*)를 지웁니다. 거부하거나 철회해도 사이트의 모든 기능을 그대로 쓸 수 있습니다.

선택 내용은 이 브라우저의 로컬 저장소(servi:consent)에만 저장되며 운영자에게 전송되지 않습니다. 브라우저 데이터를 지우면 다시 묻습니다.

2. 처리하는 개인정보와 목적

구분항목목적보유 기간
방문 통계 (동의한 경우에만) Google 애널리틱스 쿠키 식별자, 방문한 페이지 주소·제목, 이전 페이지 주소, 방문 시각, 브라우저·운영체제·기기 종류, 화면 크기, 언어, IP 주소로 추정한 대략적 지역, 사이트 안의 동작(내려받기·릴리스 노트·복사 단추 누름, 분류 선택, FAQ 펼침) 방문자 수와 많이 찾는 제품·질문을 파악해 사이트와 프로그램을 개선 Google 애널리틱스 속성의 데이터 보존 기간 설정(기본 2개월) 동안 보관 후 자동 삭제. 쿠키는 최대 2년이며 철회 시 즉시 삭제
서버 접속 기록 (모든 방문) IP 주소, 접속 시각, 요청 주소, 응답 코드, 이전 페이지 주소, 브라우저 정보 보안 사고 대응과 장애 분석 서버의 로그 회전 주기에 따라 삭제

운영자는 Google 애널리틱스의 광고 기능, Google 신호, 사용자 ID 기능을 쓰지 않으며 수집한 정보로 개인을 식별하려 하지 않습니다. Consent Mode의 광고 관련 항목(ad_storage, ad_user_data, ad_personalization)은 항상 거부 상태입니다.

4. 동의와 관계없이 브라우저가 직접 연결하는 외부 서비스

아래 서비스는 화면 표시와 내려받기를 위해 이용자의 브라우저가 직접 요청합니다. 이 과정에서 각 서비스가 IP 주소와 브라우저 정보를 받을 수 있으며, 운영자는 그 정보를 받지 않습니다. 각 서비스의 개인정보처리방침이 적용됩니다.

  • Google Fonts (fonts.googleapis.com, fonts.gstatic.com): 영문 글꼴
  • jsDelivr (cdn.jsdelivr.net): 한글 글꼴
  • GitHub (api.github.com, github.com): 최신 릴리스 정보 조회, 프로그램 내려받기와 소스 저장소

5. 파기

보유 기간이 끝난 정보는 Google 애널리틱스와 서버의 자동 삭제 기능으로 지워지며, 운영자는 별도 사본을 만들지 않습니다.

6. 이용자의 권리와 행사 방법

  • 방문 통계 동의는 1항의 쿠키 설정에서 언제든 철회할 수 있습니다.
  • 브라우저 설정에서 쿠키를 지우거나 막을 수 있으며, Google이 제공하는 Google 애널리틱스 차단 브라우저 부가기능을 쓸 수도 있습니다.
  • 개인정보 열람·정정·삭제·처리정지 요청은 아래 연락처로 보내 주십시오. 다만 운영자는 이름·이메일 등을 받지 않아 특정 이용자의 기록을 찾을 수 없는 경우가 있습니다.

7. 만 14세 미만 아동

사이트는 회원가입이 없고 연령을 확인하지 않으며 아동의 개인정보를 따로 수집하지 않습니다.

8. 안전성 확보 조치
