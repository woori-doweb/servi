ohmyZip

압축 파일을 열어 내용을 보고, 풀고, 테스트하고, 새로 만들거나 항목을 고치는 Windows 압축 관리자입니다.

내려받기 릴리스 노트

Windows 10 1809+ / 11 (x64) · zip 배포본 · GitHub 릴리스 · SHA-256

할 수 있는 일

형식은 확장자가 아니라 파일 내용으로 판별합니다.

열고 찾기

ZIP·7Z·RAR·TAR·GZ·TGZ를 열어 폴더 트리와 목록으로 봅니다. 압축 파일 전체에서 와일드카드로 이름을 찾습니다.

안전한 풀기

대상 폴더 밖을 가리키는 경로·링크 항목은 거부합니다. 취소하면 이번 작업에서 만든 파일을 지우고 덮어쓰던 파일은 되돌립니다.

알아서 풀기

최상위 항목이 하나면 그 자리에, 여러 개면 압축 파일 이름 폴더에 풉니다.

새로 압축

ZIP·7Z·TAR·TAR.GZ·GZ로 만듭니다. 압축 레벨, AES-256 암호, 7Z 파일 이름 암호화, 분할 크기를 고릅니다.

항목 고치기

파일 추가·삭제·이름 바꾸기. 임시 파일에 쓰고 성공해야만 바꾸므로 실패해도 원본은 그대로입니다.

탐색기 메뉴

오른쪽 클릭으로 열기, 압축 풀기, 여기에 풀기, 폴더에 풀기, 알아서 풀기. 현재 사용자 범위에만 등록하므로 관리자 권한이 필요 없습니다.

설치와 업데이트

설치 프로그램 없이 압축을 풀어 실행합니다.

  • Windows 10 1809 이상 또는 Windows 11 (x64)
  • .NET Desktop Runtime 9 (x64) — 없으면 Microsoft 공식 사이트에서 설치합니다.
  • 받은 zip을 원하는 폴더에 풀고 ohmyZip.exe를 실행합니다.
  • 새 버전은 하루 한 번 GitHub 릴리스에서 확인합니다. 환경 설정에서 끌 수 있습니다.
  • 영어가 기본이며 한국어 화면이 함께 들어 있습니다.

아직 코드 서명이 없어 처음 실행할 때 Windows가 경고할 수 있습니다. 릴리스의 SHA-256 파일로 받은 파일을 확인할 수 있습니다.
